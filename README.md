# 🖥️ Network-Controlled Custom CMD Panel (TCP Sockets)

This project implements a **custom command panel** built with **Python TCP sockets**, enabling **remote command execution, real-time monitoring, and multi-client management**.  
It demonstrates practical networking concepts, secure communication, and scalable design.

---

## 📌 Overview

- Designed a **client-server architecture** using Python sockets.  
- Allows **remote control of CMD commands** across connected clients.  
- Supports **multi-client management** with real-time monitoring.  
- Built as part of networking coursework to explore **practical applications of TCP/IP protocols**.

---

## ⚙️ Features

- 🔗 **TCP Socket Communication** — reliable client-server connection.  
- 🖥️ **Remote Command Execution** — send and execute system commands remotely.  
- 👥 **Multi-Client Support** — manage multiple clients simultaneously.  
- 📡 **Real-Time Monitoring** — track active connections and executed commands.  
- 🔒 **Secure & Scalable** — structured design for future enhancements.

- **Concepts:** TCP/IP, Socket Programming, Client-Server Architecture  
- **Modules:** `socket`, `os`, `threading`
